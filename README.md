# Asset Vault

Full-stack Asset Management System with React frontend and Django backend.

## Project Structure

- **asset-vault-frontend/** – React (Vite + TypeScript) frontend
- **BankAssetBackend/** – Django REST API backend
- **Repo-Git-Frontend/** – Legacy frontend reference

## Quick Start

### Backend (Django)
```bash
cd BankAssetBackend
python -m venv venv
venv\Scripts\activate   # Windows
pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
```

### Frontend (React)
```bash
cd asset-vault-frontend
npm install
npm run dev
```
